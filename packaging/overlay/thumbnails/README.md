# thumbnails/ — output of `thumbnail-generator`

One folder per video: `thumbnails/<slug>/thumb.json` (the concept manifest you review before any
credits are spent), `generated/<concept>_v<n>.png` (the 16:9 renders), and the titled finals from
`add_title.py`. Needs the `higgsfield` CLI logged in and 4-8 photos of you in `assets/face-refs/`.
